# Team Swap

Team Swap — небольшой конструктор карточек для обмена рабочими сменами. Сотрудник указывает дату и время смены, отмечает подходящие дни, выбирает навыки и получает готовую PNG-карточку для рабочего чата.

Сайт работает целиком в браузере: введённые данные не отправляются на сервер, а незаконченный черновик хранится только в локальном хранилище устройства.

> **Важно:** это независимый неофициальный проект. Он не является продуктом или внутренней утилитой Яндекса и не связан с ООО «Яндекс». Названия и товарные знаки принадлежат их правообладателям.

## Что умеет сайт

- выбирать дату смены, для которой требуется замена;
- задавать время начала и окончания смены;
- отмечать несколько доступных дат из разных месяцев и лет;
- одновременно выбирать навыки «Голос» и «Чат»;
- добавлять и удалять несколько собственных навыков;
- автоматически подгонять длинный текст под размеры карточки;
- переключаться между тремя стилями карточки: Team Yellow, «Еда / Warm» и Studio Dark;
- показывать изменения в живом предпросмотре;
- скачивать карточку в PNG или копировать её в буфер обмена;
- сохранять черновик в браузере;
- работать на компьютерах и мобильных устройствах.

## Как пользоваться

1. В блоке «Смена для замены» выберите рабочий день и укажите время смены.
2. В календаре отметьте даты, когда готовы выйти вместо коллеги. Выбранные дни появятся под календарём с названием месяца.
3. Выберите один или несколько навыков. Для собственного навыка нажмите «Свой навык», введите название и нажмите «Добавить».
4. Укажите логин и при необходимости измените комментарий.
5. Стрелками над предпросмотром выберите подходящий стиль карточки. Выбор сохранится в браузере.
6. Проверьте карточку справа. Она обновляется после каждого изменения.
7. Нажмите «Скачать PNG» или «Скопировать».

## Структура проекта

- `index.html` — разметка формы и предпросмотра;
- `styles.css` — оформление и адаптивная версия;
- `app.js` — календари, сохранение черновика и генерация PNG;
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Локальный запуск

Для обычной проверки достаточно открыть `index.html` в современном браузере. Копирование PNG может требовать защищённого адреса HTTPS; на опубликованной версии GitHub Pages оно работает в поддерживаемых браузерах.
