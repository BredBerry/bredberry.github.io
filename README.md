# Team Swap

Статический конструктор карточек для обмена сменами. Работает полностью в браузере и подходит для GitHub Pages.

## Возможности

- выбор дня, для которого нужна замена;
- указание времени начала и окончания смены;
- выбор нескольких дат, когда сотрудник готов выйти;
- готовые навыки «Голос» и «Чат», а также собственный навык;
- живой предпросмотр, скачивание и копирование PNG-карточки;
- сохранение черновика в браузере;
- адаптация под телефон и компьютер.

## Публикация

GitHub Actions автоматически публикует содержимое репозитория в GitHub Pages после каждого push в ветку `main`.
